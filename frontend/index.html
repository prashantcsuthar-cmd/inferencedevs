THE MECHANISM / 01

Structural control
during generation.

Instead of relying only on instructions or retrying invalid output, constrained decoding limits the token choices available at each generation step according to the supported grammar state.

SYSTEM DESIGN / 04

From schema
to token selection.

ICE sits in the decoding path. It does not replace the language model: it constrains which tokens can be selected at each step according to the supported grammar.

CORE DECODING LOOP

Compatibility becomes a logits mask.

Let the model produce logits z. ICE constructs a mask from the current grammar state: compatible tokens receive zero, while incompatible tokens receive negative infinity.

MASKED LOGITS z′ = z + M(S, V) ALLOW / SUPPRESS
